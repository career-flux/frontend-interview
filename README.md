# Frontend Interview

프론트엔드의 기본기 학습/면접 질문 준비를 위한 프로젝트예요.  
공개 프로젝트로 누구나 콘텐츠 작성자이자 리뷰어가 될 수 있어요.

This project is designed for learning frontend fundamentals and preparing for interviews. As an open-source project, anyone can participate as a content writer or reviewer.
